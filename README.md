# 声镜 Sonic Mirror

基于 **Vite 8 + Vue 3 + TypeScript** 构建的实时人声音高曲线监测与 88 键标准音参考钢琴。

## 功能特性

- **实时麦克风音高记录**：采用 YIN 算法（CMNDF + 抛物线插值）客观记录当前唱歌音高（如 `C5`、`E4`）、唱名简谱、精确频率（Hz）与 `-50¢ ~ +50¢` 音分偏移。
- **音高曲线与悬停回看**：高清 Canvas 实时绘制平滑人声轨迹，支持鼠标悬停曲线查看当时音高详情、拖拽回看历史与纵轴自动跟随；关闭自动跟随后纵轴一屏显示更多音，可用鼠标滚轮上下滚动。
- **琴缝音标记**：按整个长音判断音准（颤音取平均，滑音、挑音和经过音不计），平均音高偏离最近琴键 ≥ 30¢ 且持续 ≥ 0.3 秒的音在曲线上标红，并注明偏高或偏低多少音分；唱的过程中实时标出。
- **88 键标准音钢琴**：完整 `A0–C8` 88 键真实钢琴 MP3 离线采样（另带柔和电钢、纯净正弦音色），支持电脑键盘弹奏、持续参考音定音线与 A4 基准音校准（432–446 Hz）。

## 本地开发与部署

```bash
pnpm install
pnpm dev       # 本地开发
pnpm build     # 类型检查并构建生产包
pnpm run deploy  # 构建并手动部署到 Cloudflare Workers (Static Assets)
```

推送到 `main` 分支后，Cloudflare Workers Builds 会自动构建并部署。
